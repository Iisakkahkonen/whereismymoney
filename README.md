# whereismymoney

Where is all of Finland's money going? An open source tool for browsing public numbers about Finnish public finances: where the money comes from, and where it goes, down to benefits, grants to organisations and payments to companies, as far as the public data allows.

Status: planning. Nothing is built yet. See [`docs/PLAN.md`](docs/PLAN.md) for the plan and [`docs/HANDOFF.md`](docs/HANDOFF.md) for the current state.

Licence: Apache 2.0. Data comes from public sources listed in the plan; each source's own licence and credit requirements apply (for example, Kela open data is CC BY 4.0).
